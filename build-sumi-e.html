案例 A · 深入拆解

一步步做出「水墨圆环」

这是案例 A——那张随声音作画的水墨页面——的完整拆解。我们从一张空白宣纸开始，用 11 步把它做成成片，而每一步都只是你粘进 Gemini 的一句大白话。你不写代码；你描述、你运行、你检查，然后说下一句。

▶ 先玩成品 ↓ 开始 11 步 看 11 步结果图 → 第 3 天完整课程

动手前 · 三样东西

  • Google AI Studio Build — 登录后选择 Build 和网页应用，逐条粘贴下方提示词。
  • 用 localhost 打开 — 麦克风、摄像头在 file:// 会被浏览器拦掉；课前用 python3 -m http.server 起一个本地服务器，再开 localhost。
  • 一段音乐（可选） — 准备自己创作或获授权的音频；没有也行，第 11 步提供点击播放后才启动的内置合成器。

每一步都跑同一个循环：描述 → 预览 → 验证 → 迭代。每次跑通，先存一份再往下改——「上一个能跑的版本」是你最好的安全网。

11 步阶梯

第 1 步搭好骨架，第 2–11 步都在同一个对话里继续说，每句加一样新能力。看步骤与结果图 →

1

宣纸与第一道墨环

目标 — 一张暖色宣纸，正中一道手绘感的墨环。先证明「一句话变出一个页面」。

提示词 · 复制粘贴给 Gemini 
制作一个自包含的 HTML 文件：使用一个全屏 canvas 画布和原生 JavaScript，不引入任何库。
将背景填为暖米白色宣纸（#FAF6F0）。在画布正中央画一道柔和的黑色水墨圆环：
边缘略微不规则、轻轻起伏，像毛笔一笔画出的环，而不是完美的几何圆。
四周保留大量安静的留白，整体优雅、简洁。
✓ 验证
  • 正中一道墨环，边缘像毛笔画的、不是完美圆。
  • 底色是暖米白，不是纯白。
底层揭秘
沿圆周加一点正弦扰动，半径不再恒定，边缘就「毛」了。圆周可用约 100 段线段绘制。
2

让它呼吸 + 墨痕拖尾

目标 — 墨环缓缓起伏；画面不每帧清空，让运动留下渐渐渗进纸里的拖尾。

提示词 · 同一个对话，继续说 
在同一个文件中为画面添加动画。让墨环持续缓慢地呼吸：半径和边缘轻轻起伏、脉动。
关键是不要在每一帧彻底清空画布，而是在每一帧用接近透明的宣纸底色矩形
覆盖整个画面（透明度约 8%），让运动的墨迹留下柔和、细腻的拖尾，逐渐淡入纸面。
如果用户开启了 prefers-reduced-motion（减弱动态效果），就大幅减弱运动。
✓ 验证
  • 墨环慢慢起伏，像在呼吸。
  • 运动留下会淡去的墨痕，而不是干净清空。
底层揭秘
「拖尾」= 每帧铺一层 8% 的纸色，旧画面通过 fillRect 被慢慢盖住而非抹掉。
3

放进音乐

目标 — 一个播放/暂停键 + 选本地 mp3，用 Web Audio 读出声音的频率。安全键从第一刻就在。

提示词 · 同一个对话，继续说 
加入音频。在页面底部放置小巧、雅致的“播放／暂停”按钮和“选择本地音频文件”控件。
把选中的 MP3 文件载入 audio 元素，并用 Web Audio API 读取声音：
创建一个 AnalyserNode，将 fftSize 设为 256，以便每一帧读取声音的频率数据。
始终显示“暂停”和“静音”控件，不要自动播放或突然大声播放。
✓ 验证
  • 选一段 mp3，能播；暂停键真的能停。
  • 暂停键真的能停；并按提示词要求保留「静音」键。
底层揭秘
AnalyserNode 是「听诊器」,fftSize 256 把声音切成 128 个频率格子供每帧读取。
4

随低音起伏

目标 — 把墨环接到声音上：低音越重，环越大越粗；安静时收住。这是整个页面的「核心耦合」。

提示词 · 同一个对话，继续说 
现在让墨环随音乐变化。每一帧从分析器读取低频（低音）能量，
只使用最低的几个频率格子，并在时间上进行平滑处理。
用这个低音值控制墨环的大小和线条粗细：低音强时，墨环膨胀、变粗；
安静的段落中，墨环收敛、平静下来。让运动自然流畅，不要突跳。
✓ 验证
  • 低音一来，环就胀大变粗。
  • 安静段落它平稳下来，不抖。
底层揭秘
只取最低约 3 个频格当「低音」，再做平滑（lerp 0.15）避免突跳。
5

重拍泼墨

目标 — 检测强低音（自适应阈值，会自调），每一拍泼出一团墨点：飞出、变慢、扩散、渗进纸里。

提示词 · 同一个对话，继续说 
加入随重拍泼墨的效果。用自适应阈值检测强低音：每次触发后提高阈值，
再让它慢慢衰减，使它自动适应不同音乐，而不是使用固定数值。
每次检测到强拍，就从中心向外喷出约 30 个墨滴。墨滴飞出后受摩擦影响逐渐减速，
随着速度降低而扩散变大，并在约一秒内干燥、淡入纸面。
大部分墨滴为黑色，少量为青色或铜色，偶尔出现淡金色。
加入持续几帧的短暂冷却，防止每一帧都连续触发。
✓ 验证
  • 强拍泼墨，墨点扩散后干进纸里。
  • 安静处不乱泼；绝不频闪。
底层揭秘
自适应阈值 + 冷却帧，让它跟着歌自调、又不会狂泼；墨点变慢时才「长大变淡」=渗墨。
6

三层墨环 + 鼠标视差

目标 — 把一道环变三层（外淡、中实、内锐），跟着鼠标以不同速度位移，做出景深。

提示词 · 同一个对话，继续说 
增强画面的纵深感。使用三道大小和透明度不同的同心水墨圆环：
外圈大而淡，像晕染；中圈笔触厚实；内圈小而锐利，作为点睛。
让三道环跟随鼠标，并使用不同的位移幅度：内圈移动最多，外圈最少，形成视差景深。
加入约三分之一秒的柔和迟滞，让圆环平滑地漂向鼠标位置，不要瞬间跳过去。
✓ 验证
  • 看得出三层环，深浅不同。
  • 移动鼠标，三层以不同速度滑动，有迟滞。
底层揭秘
视差 = 同一中心、不同位移倍数（内层乘得最大）；迟滞用每帧 lerp 实现。
7

冲击波扭曲

目标 — 每个强拍（和点击）从中心放出一圈冲击波，所过之处把画面轻轻推开、扭曲，再淡去。

提示词 · 同一个对话，继续说 
加入冲击波。每逢强拍，以及每次点击时，都从中心发出一圈向外扩张的波，
让它所经过的画面发生位移和扭曲：波前到达某个点时，轻轻将该点向外推开，
再让冲击波随着扩张逐渐淡去。保持扭曲克制、优雅，像涟漪穿过湿润的墨迹。
✓ 验证
  • 强拍/点击送出一圈涟漪，墨随之弯曲。
  • 扭曲克制、优雅，不刺眼。
底层揭秘
所有要画的点都先过一道「位移函数」：落在波前附近就被推开，于是整幅画被同一只手扭。
8

拖动作画

目标 — 让人能直接在宣纸上按住拖动，留下自己的墨笔触，慢慢渗开淡去。

提示词 · 同一个对话，继续说 
让我能够作画。用鼠标在纸面按住并拖动时，沿移动路径留下柔和的水墨笔触点，
让它们轻微起伏，缓缓渗入纸面并淡去，像湿毛笔划过宣纸。
这些笔触使用当前的墨色。
✓ 验证
  • 按住拖动，留下会渗开淡去的笔触。
底层揭秘
每个落点存进一个数组，各自带透明度逐帧衰减 + 抖动 → 自然的「湿笔」。
9

滚轮调色 + 中轴线

目标 — 滚轮在「青」与「铜」之间调色，整幅画一起变；再添一条贯穿上下的淡淡中轴线——画面的脊。

提示词 · 同一个对话，继续说 
加入鼠标滚轮调色。向上滚动时，让整幅画的色调向暖铜色变化；
向下滚动时，让色调向冷青绿色变化。
用一个 tone 值在冷青色与暖铜色之间插值，并用它统一控制墨环、泼墨、
笔触，以及页面正中央一条淡淡的竖直中轴线。中轴线是整件作品的脊梁。
✓ 验证
  • 上滚转暖（铜），下滚转冷（青），整体同步。
  • 中间多了一条淡淡的竖轴。
底层揭秘
一个 0→1 的 tone 值在青（91,140,126）与铜（176,141,87）之间插值，一处改、处处变。
10

用你的声音 · 麦克风

目标 — 加一个麦克风开关：你越大声，中心那团光芯越亮（颜色随当前青↔铜色调）；拍一下手（音量骤起）就炸出一团墨。

提示词 · 同一个对话，继续说 
加入一个标为“麦克风”的开关。开启时请求权限，并用独立的分析器读取麦克风。
用我的音量控制画面中央发光的金色光芯：说话或唱歌越响，光芯就越明亮、越大。
检测拍手，也就是音量突然升高，并在拍手时触发一次泼墨爆发。
提醒：麦克风只能在 localhost 或 HTTPS 环境下工作，不能直接在 file:// 页面中使用。

AI Studio Build 预览设备输入时，还要在 metadata.json 的 requestFramePermissions 中加入 microphone，并确认预览权限提示。

✓ 验证
  • 说话/唱，中心光芯随音量发光长大。
  • 拍手，炸出一团墨。在 localhost 下测。
底层揭秘
「拍手」= 音量的突然跳变（这一帧比上一帧猛涨且够响）就触发爆发，而不是看绝对音量。
11

收尾：摄像头 · 内置合成器 · 安全控件

目标 — 最后一层。让身体参与互动；没有音频文件时点击播放也能启动合成器；并把「计分的安全规则」一次性加进去。

课堂提醒 — 运行成品展示了交互方向；在你自己的作品中，静音、减弱动效、温和闪光与暂停仍是需要逐项实现和验证的计分要求。

提示词 · 同一个对话，继续说（这条最长，可分两次发） 
最后，在同一个文件里加入三项内容。
（1）加入“摄像头”开关：获得权限后，将每一帧摄像头画面与上一帧比较，
    找到发生运动的位置，再用运动的水平位置改变墨环的视差。
    当人向左右倾身或挥手时，墨迹随身体一起漂移。
（2）没有载入音频文件时，允许用户点击“播放”，启动内置的舒缓环境音乐合成器，
    速度为每分钟 50 拍：柔和的低音脉冲，偶尔加入延长的五声音阶音符。
    页面打开时不要自动播放音频。
（3）安全要求也计入评分：所有闪光保持温和，每秒不超过约三次，
    绝不使用全屏白色频闪；开启 prefers-reduced-motion（减弱动态效果）时，
    禁用画面抖动；“暂停”和“静音”控件始终可见。

若在 AI Studio Build 预览摄像头，还要在 metadata.json 的 requestFramePermissions 中加入 camera，并确认预览权限提示。

✓ 验证
  • 对着摄像头左右动，墨随之漂移。
  • 不放文件时点击播放也能发声；闪光温和；开了「减弱动效」后抖动应停；暂停/静音键都在。
底层揭秘
摄像头不做人脸识别，只把「这一帧和上一帧哪里不一样」的重心算出来当方向——便宜、稳、够用。
